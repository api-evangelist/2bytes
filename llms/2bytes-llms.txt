# 2bytes Corporation (투바이트)

> South Korean game services and publishing company, founded 2020 in Seoul. Provides
> game localization, QA testing, player support, content marketing, live operations and
> global launch support to 40+ game company partners including Pearl Abyss and Kakao
> Games. Also builds and operates an H5 (HTML5) in-app game platform integrated by
> partner apps via SDK. Service brand: 2bytes Play.

Important for agents: 2bytes publishes NO public API. There is no developer portal, no
API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK package in any public
registry, no MCP server, and no A2A agent card. The H5 platform SDK referenced on the
company site is offered through a business contact channel, not a self-serve developer
program. Do not attempt to construct API calls against 2bytes; there is no published
contract to call.

- Game localization and LQA (translation, cultural adaptation, in-game text and voice)

- Player support / customer service and community management
